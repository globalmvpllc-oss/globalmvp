# Small Business Finance SaaS MVP — FinanceFlow

## Overview
A global-first financial management SaaS for small businesses, freelancers, and solo entrepreneurs. Core workflow: Create invoice → Send → Track due date → Record payment → See financial impact on dashboard.

## Tech Stack
- Next.js 14 App Router, TypeScript, Prisma + PostgreSQL
- NextAuth v4 (JWT strategy, credentials provider)
- Tailwind CSS + shadcn/ui components
- Recharts for data visualization
- HTML2PDF API (Abacus) for invoice PDF generation
- AWS S3 for file attachments

## Color & Theme
- Primary: purple (#7C3AED / HSL 262 83% 58%)
- Light mode default, clean professional look
- Fonts: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (numbers/code)

## Architecture
- `(app)` route group with layout that includes sidebar + auth guard
- API routes all gated with `requireAuth()` which derives userId from session
- All company data scoped by `companyId` from `CompanyMember` table
- Onboarding flow creates company + default categories on first login

## Navigation (Sidebar)
Dashboard, Invoices, Customers, Income, Expenses, Payments, Calendar, Reports, Settings

## Key Modules
1. **Dashboard**: Revenue/Expenses/Profit/Receivables/Upcoming metrics + activity feed
2. **Invoices**: Full CRUD, statuses (DRAFT→SENT→PAID etc), PDF generation, payment recording
3. **Customers**: CRUD with detail page showing invoice history and financials
4. **Income**: Track with categories, customers, statuses (EXPECTED/RECEIVED)
5. **Expenses**: Track with categories, vendors, statuses (UNPAID/PAID)
6. **Payments**: Record payments linked to invoices/expenses, auto-update statuses
7. **Calendar**: Visual monthly calendar with invoice/expense due dates and payments
8. **Reports**: Summary metrics + bar chart (income vs expenses) + pie charts (categories, status)
9. **Settings**: Company info, location, tax info (Turkey-specific fields when country=TR)

## Currencies
USD, EUR, GBP, TRY supported. Architecture allows adding more.

## Out of Scope (MVP)
AI features, bank integrations, e-Fatura/e-Arşiv, payroll, inventory, double-entry accounting, enterprise features

## Billing
